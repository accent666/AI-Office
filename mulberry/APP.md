# MULBERRY для Android: как собрать, выложить и обновлять

Простыми словами, по шагам. Делается один раз, дальше всё автоматически.

## Что где лежит
- `client/` — сама игра (тот же `index.html`, что в Telegram). Горизонтальная вёрстка — блок `LANDSCAPE` в конце `<style>`; в портрете (Telegram) всё как раньше.
- `app/` — Android-приложение на Capacitor: обёртка над `client/`. Все картинки, звуки и шрифты лежат внутри APK.
  - `app/android/` — Android-проект (альбомная ориентация, полный экран, тёмный фон `#0d090b`, пакет `club.mulberry.game`).
  - `app/assets/` — исходники иконки и сплэша (сделаны из `client/c/logo.svg`).
- `.github/workflows/mulberry-apk.yml` (в корне репозитория) — GitHub сам собирает подписанный APK.
- `server/` — `api.py` и `bot.py` с входом из приложения. Что поменялось — `server/CHANGES.md`.

## Ключ подписи (keystore): ВАЖНО
APK подписан ключом `mulberry-release.jks`. **Обновление ставится поверх старой версии, только если подписано тем же ключом.**
Потеряешь ключ — у всех игроков придётся удалять игру и ставить заново (баланс не пропадёт, он на сервере, но это неудобно).
- Сохрани `mulberry-release.jks` и `KEYSTORE.txt` (пароль) в двух местах: например, в «Избранном» Telegram и на флешке или в облаке.
- Никому их не отправляй и не клади в репозиторий.

## Один раз: секреты в GitHub (5 минут)
1. Открой репозиторий на github.com → **Settings** (шестерёнка сверху) → слева **Secrets and variables** → **Actions**.
2. Нажми зелёную **New repository secret** и добавь 4 секрета (имя → значение, всё есть в `KEYSTORE.txt`):
   - `KEYSTORE_BASE64` → длинная строка из `KEYSTORE.txt` (это сам ключ, записанный текстом)
   - `KEYSTORE_PASSWORD` → пароль
   - `KEY_ALIAS` → `mulberry`
   - `KEY_PASSWORD` → тот же пароль
3. Влей ветку с приложением в `main` (кнопка **Merge pull request**). Кнопка запуска сборки появляется, только когда workflow лежит в `main`.

## Собрать APK
1. Вкладка **Actions** → слева **MULBERRY APK** → справа **Run workflow** → **Run workflow**.
2. Подожди 5–8 минут, пока не появится зелёная галочка.
3. Открой этот запуск → внизу **Artifacts** → **MULBERRY-apk**. Скачается zip, внутри `MULBERRY-<номер>.apk`.
4. Этот `.apk` и выкладываешь в канал.

Сборка также запускается сама при каждом изменении `mulberry/client` или `mulberry/app` в `main`.

## Выпустить обновление
1. Поменял игру → изменения попали в `main` → Actions собрал новый APK (номер сборки растёт сам: 2, 3, 4…).
2. Выложи новый `.apk` в канал.
3. Попроси админа сервера поменять число в `version.json` на номер этой сборки (номер есть в имени файла и в итоге запуска Actions):
   `{"apk": 5, "url": "https://t.me/твой_канал"}`
   У всех, у кого старая версия, при запуске появится плашка «Вышло обновление» с кнопкой, которая открывает канал.

Первая сборка (`MULBERRY-1.apk`) сделана вручную, у неё номер 1. Сборки из GitHub начинаются с 2.

## Как это устроено (коротко)
- **Вход.** В профиле приложения кнопка «Войти через Telegram» → открывается бот → нажимаешь «Войти» → возвращаешься в игру, и она уже с твоим балансом и скинами. Токен входа хранится в приложении; кнопка «Выйти из аккаунта» в профиле.
  Бот спрашивает подтверждение кнопкой, а не входит сразу по ссылке: так нельзя украсть аккаунт, прислав кому-то чужую ссылку входа.
- **Сеть: CORS, а не CapacitorHttp.** Приложение ходит на `https://2-56-120-214.sslip.io/monaco/api/` обычным `fetch`, а сервер разрешает origin приложения (`https://localhost`).
  Почему так: CapacitorHttp подменяет `fetch` целиком, и тогда загрузка звуков и картинок из самого APK тоже идёт через него, а это лишний риск сломать то, что сейчас работает. CORS — 10 строк в `api.py`, и клиент остаётся одинаковым в Telegram и в приложении.
- **Telegram-функции вне Telegram:** вибрация через Capacitor Haptics, «Позвать друга» через системное «Поделиться» (ссылка на бота), «Назад» Android работает так же, как кнопка «Назад» в Telegram (сначала закрывает открытые шторки, на главной сворачивает игру).
- Telegram Mini App работает как раньше: и для вёрстки, и для входа по initData.

## Собрать на своём компьютере (необязательно)
Нужны Node 22, JDK 21 и Android SDK. В `mulberry/app`: `npm ci && npx cap sync android && cd android && ./gradlew assembleRelease`
(для подписи задай переменные `KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).
Иконки и сплэш пересоздаются командой `npm run assets` из картинок в `app/assets/`.
