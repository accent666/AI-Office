# MULBERRY — Android-приложение (APK)

Здесь лежит Android-версия игры MULBERRY. Мини-апп в Telegram — отдельно, его эти файлы не трогают.

| Папка / файл | Что это |
|---|---|
| `www/` | сама игра: `index.html`, картинки (`c/`), звуки (`s/`), шрифты (`f/`) |
| `android/` | Android-проект (Capacitor 8), из него собирается APK |
| `capacitor.config.json` | настройки приложения (имя, id `club.mulberry.game`, цвет фона) |
| `screenshots/` | картинки «до / после» |
| `tools/` | скрипты, которые снимают скриншоты всех экранов и ищут проблемы |
| `../.github/workflows/mulberry-apk.yml` | сборка APK на GitHub (кнопкой) |

Версия: **1.2.0** (номер сборки `versionCode` = **3**).

---

## Как установить APK на телефон

1. Скачай файл `MULBERRY-1.2.0.apk` на телефон (через Telegram «Избранное», Google Диск или кабель).
2. **Важно (только в первый раз):** новая версия подписана **новым ключом**. Поэтому старую MULBERRY
   нужно сначала **удалить** (долгое нажатие на иконку → «Удалить»). Иначе Android скажет
   «Приложение не установлено» / «конфликт пакетов».
   - Если играл **через вход Telegram** — баланс и скины сохранятся на сервере, ничего не пропадёт.
   - Если играл **как гость** — гостевой прогресс хранится на телефоне и при удалении пропадёт.
3. Открой скачанный APK. Телефон спросит разрешение «Устанавливать из этого источника» — разреши.
4. Нажми «Установить». Готово.

Дальше обновления будут ставиться **поверх**, без удаления — если подписывать тем же ключом (см. ниже).

---

## 🔑 Ключ подписи — самое важное

- Файл ключа: `mulberry-release.jks`, псевдоним (alias): `mulberry`, пароль — в файле `ПАРОЛЬ-КЛЮЧА.txt`.
- Эти два файла **не лежат в репозитории** (и не должны). Сохрани их в **двух** надёжных местах,
  например на флешке и в облаке (Google Диск) в отдельной папке.
- **Если потеряешь ключ или пароль — обновление поверх больше не выпустить никогда.** Придётся
  снова просить всех удалять приложение.
- Никому не отправляй ключ и пароль и не выкладывай их в GitHub.

## Как выпустить обновление

### Шаг 1. Поменять игру
Правишь `www/index.html` (или картинки в `www/`).

### Шаг 2. Поднять номер версии
В файле `android/app/build.gradle` найди и увеличь:
```
versionCode 3        ← +1 каждый раз (4, 5, 6…)
versionName "1.2.0"  ← как хочешь назвать версию, например "1.2.1"
```
Без увеличения `versionCode` телефон не поставит обновление поверх.

### Шаг 3. Собрать APK — вариант А: на GitHub (проще всего)

Один раз нужно добавить ключ в «секреты» репозитория:

1. Преврати файл ключа в текст (base64):
   - **Windows** (PowerShell, в папке с ключом):
     `[Convert]::ToBase64String([IO.File]::ReadAllBytes("mulberry-release.jks")) | Set-Clipboard`
     — текст скопируется в буфер обмена.
   - **Mac / Linux:** `base64 -i mulberry-release.jks | pbcopy` (Mac) или `base64 -w0 mulberry-release.jks` (Linux).
2. На GitHub открой репозиторий → **Settings** → **Secrets and variables** → **Actions** →
   **New repository secret** и добавь 4 секрета:

   | Имя | Значение |
   |---|---|
   | `MB_KEYSTORE_BASE64` | текст из пункта 1 |
   | `MB_KEYSTORE_PASSWORD` | пароль из `ПАРОЛЬ-КЛЮЧА.txt` |
   | `MB_KEY_ALIAS` | `mulberry` |
   | `MB_KEY_PASSWORD` | тот же пароль |

Потом каждый раз:

1. Закоммить и запушь изменения (сборка запустится сама), **или** открой вкладку **Actions** →
   слева **MULBERRY APK** → кнопка **Run workflow** → выбери свою ветку → **Run workflow**.
2. Подожди ~5–8 минут, пока кружок станет зелёной галочкой ✅.
3. Нажми на этот запуск → внизу страницы раздел **Artifacts** → **MULBERRY-apk** — скачается zip.
4. Распакуй zip — внутри `MULBERRY-<версия>.apk`. Его и ставь на телефон.

Если запуск красный ❌ с ошибкой «Нет секрета MB_KEYSTORE_BASE64» — значит, не добавлены секреты (см. выше).

### Шаг 3. Собрать APK — вариант Б: на своём компьютере
Нужны Node.js 22, JDK 21 и Android SDK (проще всего — поставить Android Studio).
1. Создай файл `android/keystore.properties` (в git он не попадёт):
   ```
   storeFile=C:/путь/к/mulberry-release.jks
   storePassword=ПАРОЛЬ
   keyAlias=mulberry
   keyPassword=ПАРОЛЬ
   ```
2. В папке `mulberry-app`:
   ```
   npm ci
   npx cap sync android
   cd android
   ./gradlew assembleRelease      (на Windows: gradlew.bat assembleRelease)
   ```
3. Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`.

## Что поменялось в версии 1.2.0
- Чисто чёрная тема (фон `#000`, панели тёмно-серые, текст белый/серый), один малиновый акцент `#d42a5b` на главных кнопках; контраст текста ≥ 4.5:1. Светлая тема выключена.
- Новый блок «Настройки» в профиле: звук и ориентация экрана «Авто / Вертикальная / Горизонтальная» (выбор запоминается, работает через свой нативный плагин `Orientation`).
- Раньше APK был жёстко горизонтальный — теперь работает в обеих ориентациях, у каждой своя вёрстка (`@media (orientation: …)`).
- Все кнопки не меньше 44×44, учтён вырез камеры и системные панели (`env(safe-area-inset-*)` + переменные Capacitor).
- Столы: в горизонтали кнопки покера, стада и блэкджека — колонкой справа, стол до них не доходит; в баккаре и играх против дилера нижняя панель не налезает на бортик; комната «с другом» — соперник слева, вы справа.
- Лобби, магазин, инвентарь, профиль, шторки — без наложений и горизонтального скролла.
- Игровая логика, цены, скины, API и вход не менялись.

## Проверка скриншотами
```
NODE_PATH=$(npm root -g) node tools/shots.js www /tmp/shots     # 41 экран × 4 размера + отчёт report.json
python3 tools/sheet.py /tmp/shots /tmp/sheets                   # склейки по экранам
```
Отчёт ищет: горизонтальный скролл, кнопки за краем экрана, кнопки меньше 44 px, наложение кнопок,
ники под картами, текст с контрастом ниже 4.5:1, ошибки в консоли.
